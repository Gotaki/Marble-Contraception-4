# Marble Contraception Project – Team 4

## Overview
This repository contains the code and documentation for **Team 4's** Marble Contraception Project, developed for **ENGG2000 / ENGG3000** at **Macquarie University**.

## Project Description
The goal of this project is to design and implement a solution for the Marble Contraception challenge, integrating engineering principles, system design, and testing protocols.

## Repository Structure
- `src/` – Source code and scripts.
- `docs/` – Project documentation, reports, and design files.
- `tests/` – Test suites and validation scripts.
